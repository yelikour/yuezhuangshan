## 这是什么

《岳桩山》是一款模拟封闭互联网环境的**拟真网站型 ARG（另类现实游戏）**。
你不是在"玩一个游戏界面"，而是在翻看一个个虚构但逼真的网站——邮箱、景区官网、
聊天软件、地方资讯、会议后台——从中拼凑真相。

本项目目前为**第一阶段纵向切片（约 15 分钟开场）**。

## 核心特色

- **拟真多网站**：导航首页 / 虚构邮箱 / 景区官网 / 聊天软件 / 资讯搜索 / 会议后台，
  每个站点同时提供线索、生活化背景与少量干扰信息。
- **基于推理的谜题**：关键词搜索、口令推理、时间线矛盾——重要结论至少有两条独立线索支撑。
- **克制的恐怖**：用"安静的不对劲"营造不安，无 jump-scare，无血腥。
- **公平与无障碍**：三级渐进提示、输入标准化（不因格式差异卡关）、
  减少动态效果、默认静音、字幕、键盘可达。

## 技术栈

Vite + TypeScript + 原生 HTML/CSS，静态多页面，无后端、无数据库、无游戏引擎。

## 本地开发

```bash
npm install      # 安装依赖
npm run dev      # 启动开发服务器 http://localhost:5173
npm test         # 运行单元测试（39 个）
npm run build    # 类型检查 + 生产构建到 dist/
npm run preview  # 预览构建产物
```

## 项目结构

| 目录 | 说明 |
|------|------|
| `docs/` | 世界观圣经、时间线、线索图、游戏设计文档（权威来源） |
| `src/data/` | 剧情/答案/站点元数据（单一真相源，与文案分离） |
| `src/shared/` | 状态、进度、提示、输入标准化、存档 |
| `src/pages/` | 8 个网站页面（每站一个目录） |
| `tests/` | Vitest 单元测试 |
