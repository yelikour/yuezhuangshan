## 二、AI 生图缺口清单（按价值排序）

### P0 · 修补现有图

#### 1. `ending_ritual` 假自拍重做（竖 3:4，建议 1080×1440）
- **为什么**：这是全游戏最重的一张道具图（第一阶段高潮），但目前只传达了"氛围"，没传达"证据"。剧本要求玩家能从照片本身看出：白色祭祀袍、背景"研讨会工作人员"工牌挂钩、时间戳矛盾。
- **画面要求**：
  - 手机前置自拍视角，手臂前伸透视；欠曝偏冷但**面部必须入光**（表情"礼貌而空"，微笑弧度略对称）；
  - 白色立领祭祀长袍，领口与前襟的刺绣中"**合奘**"两个汉字**清晰可辨**（可古拙，不可乱码）；
  - 背景墙一排挂钩，其中一枚挂着工牌，牌上"**研讨会工作人员**"六字**半可读**（轻微虚焦即可，但笔画正确）；
  - 可选加彩：画面边缘一处不该出现的倒影/镜像（供二周目玩家细看）。
- **负面约束**：无血腥、无现实宗教符号、无品牌 logo、面部不得参考任何真人、文字禁止乱码。

## 三、AI 生图通用红线（每张都适用）

1. **全虚构**：不出现现实品牌、logo、真实地名标牌、现实宗教符号；"合奘教"一切纹样为原创。
2. **文字必须可读**：画面中的汉字允许轻微模糊/虚焦，但笔画必须正确——**禁止乱码假字**（乱码会立即破坏"照片证据"的说服力）。生成后人工核验所有文字。
3. **恐怖克制**：不血腥、不露骨、无 jump-scare 元素；追求"安静的不适"（对称、不该在场的物件、过分礼貌的表情）。
4. **同源一致**：菌丝形态（对称、肋骨/神经状、灰白色）在 corridor_mold / steel_door_thumb /（未来的）其他画面中保持同一种视觉语言。
5. **格式**：统一转 webp 后放入（可用 `scripts/optimize_assets.py`），横图 ≤1600px 宽、竖图 ≤1440px 高，单张 ≤600KB。

## 四、零代码接入机制（`src/assets/art/`）

- `src/data/assets.ts` 的 `art(name)` 通过 `import.meta.glob` 动态收集 `src/assets/art/*.{webp,png,jpg}`：
  - 文件存在 → 对应页面图位自动显示（`<img hidden>` 转 visible）；
  - 文件不存在 → 图位保持隐藏，页面维持纯文本形态，**功能与测试不受影响**。
- 已预留的图位（hidden img，等待对应文件名）：

| 文件名 | 图位 | 页面 |
|--------|------|------|
| `guilu_roster` | 《归山名录》标题下方 | 合奘教 · 内部文献 |
| `annals_fragment` | 县志残页正文上方 | 景区 · 古籍残页 |
| `steel_door_thumb` | 周衍回信正文之后（云相册缩略图） | 邮箱 · 周衍回信 |

- P0 的 `ending_ritual` 与既有资产同路径同名替换（`src/assets/ending_ritual.webp`），无需改动代码。
- P2 图位需要小改页面（加 hidden img + `art()` 调用，参照上表三处的写法）。

> 生成后自查：把图放入 → `npm run dev` 打开对应页面确认出现 → `npm test && npm run build` 全绿。
