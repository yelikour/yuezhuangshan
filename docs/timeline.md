# 《岳桩山》时间线 (Timeline)

> 本文档定义游戏内事件的绝对时间顺序。所有页面文案中的日期、时间必须与此一致。
> 切片剧情发生在 **2026 年**（与现实年份同步），时间跨度约 2 周。

## 一、深层历史（背景设定，部分会出现在文献中）

| 时间 | 事件 |
|------|------|
| 约 1000 年前 | 岳姓先民立木桩于山谷入口，命名岳桩村、岳桩山。发现三年一度的山溪变浑、老人自行入山现象。 |
| 约 1000 年前起 | 每 三年 正月初十，将濒死老人送至岳圣桩的传统形成。 |
| 约 200 年前 | 母体从外来者记忆学会宗教组织形式，借精神薄弱者创建"合奘教"。 |
| 约 20 年前 | 神经再生科学家"林叙之"发现母体并与其合作；母体为他修复身体，他成为人类代理（本人未察觉/不愿承认）。 |
| 约 3 年前 | 岳桩生态文化发展有限公司成立，开始将当地包装成景区。 |
| 约 1 年前 | 筹备首届"地方异闻与悬疑叙事创作研讨会"，用以筛选适配宿主。 |

## 三、玩家可推导的时间线结论（切片目标）

1. 沈苒在"失联"后仍然活动（或被带着活动）于**岳圣桩维护通道**——她并非简单失踪。
2. 结尾的"我已经回来了"是**假的**：照片细节与她的习惯、与关机状态、与维护通道时间戳全部矛盾。
3. 发信者要么是母体模仿沈苒，要么是被寄生后残留意识混杂母体意志的沈苒——玩家此时无法确定，留作下一阶段悬念。
