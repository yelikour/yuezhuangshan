# 《岳桩山》线索依赖图 (Clue Graph)

> 本文档定义每条线索的：**来源页面 → 内容 → 可推导结论 → 解锁的下一节点**。
> 设计原则（来自需求）：
> 1. 重要结论至少有**两条独立线索**支持。
> 2. 不要求玩家无提示猜测网址。
> 3. 解谜后必须揭露**新的世界规则或改变剧情**，而不只是打开下一页。
> 4. 每个谜题配**三级渐进提示**。

## 二、核心线索详表

### CLUE_INVITE
- **来源**：P01 邮箱 → 邀请函正文。
- **内容**：研讨会名称、主角的"会议账号"（用于登录后台）、抵达日期 2026-06-20。
- **结论**：主角是被定向邀请的；获得后台登录账号。
- **解锁**：P05 的"账号"字段。

### CLUE_CREDENTIAL_HINT
- **来源**：P01 入住资料页 + P03 沈苒聊天细节。
- **内容**：入住资料写明"研讨会工作人员初始口令 = 参会证编号后四位 + 研讨会拼音首字母"。
  沈苒在聊天中无意提到："你的参会证编号是不是尾号 **0427**？前台登记时我看了一眼。"
- **结论**：口令 = `0427` + `ywyxxsc`（地方异闻与悬疑叙事创作 → 取首字母，标准化见 game_design.md）。
  **最终口令（标准化后）**：`0427ywyxxsc`
- **双线索支持**：① 入住资料的口令规则；② 聊天里的编号尾号。缺一不可。
- **解锁**：进入 P06。

### CLUE_YUESHENGZHUANG_LEGEND
- **来源**：P02 景区官网 → 搜索"岳圣桩" → 传说页。
- **内容**：岳圣桩的民间传说、三年一度正月初十的"敬老"传统（被景区美化为"敬老节"）。
- **结论**：揭示【世界规则：三年一度的传统】；为 P04 旧报道日期提供文化背景。
- **支线价值**：传说页底部有一段被抹去的注释，暗示"老人入山后次年丰收"——这是可选支线。

### CLUE_THREE_YEAR_TRADITION
- **来源**：P02 搜索结果 + P04 旧报道日期交叉。
- **内容**：2019-02-14 = 当年正月初十。
- **结论**：旧失踪报道的时间与"三年一度送老传统"完全吻合——失踪不是意外。

### CLUE_LAST_NORMAL_MSG
- **来源**：P03 聊天。
- **内容**：沈苒 19:42 的"饮用水怪味"消息。
- **结论**：沈苒在失联前已察觉山庄饮用水异常（=山泉介质，呼应世界规则#4 催眠介质）。

### CLUE_ABNORMAL_PHOTO
- **来源**：P03 聊天 → 异常照片。
- **内容**：走廊尽头灭火器旁**对称生长**的灰白色菌斑。
- **结论**：山庄内部已有母体的表层菌丝网络（为 P06 维护通道埋伏笔）。

### CLUE_OFFLINE_TIME
- **来源**：P03 聊天。
- **内容**：沈苒 21:03 后离线/关机。
- **结论**：建立"失联时间锚点"，用于与 P06 刷卡记录对比。

### CLUE_TAMPERED_REPORT  ★时间线矛盾谜题#1★
- **来源**：P04 资讯搜索 → 输入"失踪"或"岳圣桩" → 命中被篡改的旧报道。
- **内容**：
  - 报道标题：《登山客周某于岳桩山自行失足，家属未提异议》（2019-02-14）
  - 但正文有一处未改干净：写着"自愿**返回平原**"，而标题是"失足"；正文末尾家属栏为空。
- **结论**：报道被修改过；失踪与"三年一度送老"传统在日期上重合，不是巧合。
- **揭露的世界规则**：母体/组织会**修改对外信息**以维持隐蔽（呼应主题：管理界面）。

### CLUE_KEYCARD_MAINTENANCE  ★时间线矛盾谜题#2★
- **来源**：P06 后台 → 房卡刷卡记录。
- **内容**：沈苒房卡在 **23:47** 和 **02:11** 两次刷于"岳圣桩维护通道"闸机。
- **矛盾**：她 21:03 就"失联/关机"了，房卡却在失联后 2.5 小时仍在被使用，且地点是普通参会者禁入的维护通道。
- **结论**：沈苒并非简单失踪；她（或带着她的人/东西）进入了维护通道。
- **双线索支持**：① 失联时间（CLUE_OFFLINE_TIME）；② 刷卡时间（本线索）。

### CLUE_FAKE_RETURN（结尾，P07）
- **来源**：P07 沈苒"已关机"账号突然发来的消息 + 照片。
- **内容**：
  - 文字："别来找我，我已经回来了。"
  - 照片矛盾细节（三条，任一即可让玩家识破）：
    1. 她穿着主角从未见过的**合奘教白色祭祀袍**。
    2. 背景墙挂着写有"研讨会工作人员"字样的工牌挂钩（她是参会者，不是工作人员）。
    3. 照片 EXIF 时间戳 = **02:11**，与维护通道内层刷卡时间完全重合；而她说"已经回来了"。
- **结论**：发信者不是真正的、自由的沈苒。
- **揭露的世界规则**：母体能**模仿宿主的语言和影像**，但会留下缝合痕迹（呼应规则#3 擅长模仿但缺乏原创理解）。

## 四、三级渐进提示（每谜题）

> 提示等级随"卡关时间/错误次数"递增，玩家也可手动请求提示。
> 提示内容**绝不直接给出答案**，只给方向。

### SEARCH_P04 提示
- L1：旧报道的标题里可能藏着一个和"岳圣桩"相关的关键词。
- L2：试试搜索"失踪"或"失足"——想想什么样的新闻会被改成"自行返回"。
- L3：输入"失踪"二字。报道日期是不是和某个三年一度的传统重合？

### LOGIN_P05_PASSWORD 提示
- L1：口令规则写在入住资料里；尾号需要问"知道你参会证的人"。
- L2：口令 = 参会证后四位 + 研讨会名称拼音首字母。沈苒在聊天里提过你的尾号。
- L3：尾号 0427，研讨会"地方异闻与悬疑叙事创作"取首字母 ywyxxsc，合起来输入。

## 五、支线页面（可选）

### 支线 A：岳氏族谱 / 数字县志片段
- **入口**：P02 传说页底部一个不起眼的"古籍引用"链接。
- **内容**：族谱残页记载"**岳圣桩下有根**"，"根"字在原文中被涂改过。

### 支线 B：合奘教宣传页（极简占位）

- **内容**：合奘教"肉身归山、记忆合一"的教义片段。
- **奖励**：为后续阶段铺垫，本切片仅作氛围。

## 六、第二阶段线索（P08–P12）

```
P07 结尾（假消息）
  │  主角决定进入维护通道
  ▼
P08 lab 门禁（身份推理谜题）
  │  需求: 访客登记表推断林叙之工位编号
  │  解锁线索: CLUE_LAB_ACCESS, CLUE_LIN_XUZHI
  ▼
P09 实验室档案（档案检索谜题）
  │  发现: 主角=理想容器, 沈苒=中等/诱饵
  │  解锁线索: CLUE_PROTAGONIST_VESSEL, CLUE_SHENRAN_DECOY, CLUE_MOTHER_CANT_LEAVE
  ▼
P10 监控录像（细节观察）
  │  发现: 02:11 躯壳用左手（沈苒是右撇子）
  │  解锁线索: CLUE_SHELL_LEFTHAND
  ▼
P11 半沈苒对话（真假消息分辨）
  │  需求: 选出真沈苒消息（芝麻猫私密记忆）
  │  解锁线索: CLUE_HALF_SHENRAN, CLUE_ONLY_WAY_OUT
  ▼
P12 最终选择（三结局）
```

### CLUE_LAB_ACCESS
- **来源**：P08 lab 门禁 → 访客登记表 + 工位分布图。
- **内容**：访客登记表显示"林叙之 工位 B-07"，门禁要输入"姓名拼音首字母+工位号"。
- **答案**：`lxzb07`（林叙之 L-X-Z + B-07，标准化后）。
- **双线索**：① 访客登记表的姓名；② 工位分布图的 B 区编号。

### CLUE_PROTAGONIST_VESSEL ★核心反转★
- **来源**：P09 档案 → "宿主适配性评估"。
- **内容**：主角评级 S（理想容器：人格整合力强、记忆承载力高）。
- **揭露的世界规则**：呼应主题——玩家越擅长调查，越证明自己适合当容器。

### CLUE_SHENRAN_DECOY
- **来源**：P09 档案 → 沈苒评级。
- **内容**：沈苒评级 B（中等），用途标注"诱饵：用于引导 S 级目标进入"。
- **结论**：沈苒从一开始就是用来钓主角的。

### CLUE_MOTHER_CANT_LEAVE
- **来源**：P09 档案检索 → 交叉查询编号。
- **内容**：实验日志"主体无法脱离根脉网络；离山需 S 级容器携带记忆核心"。
- **揭露的世界规则**：母体无法离山（规则#1）+ 需要适配宿主（规则#8）。

### CLUE_SHELL_LEFTHAND
- **来源**：P10 监控 → 02:11 录像。
- **内容**："沈苒"用左手按闸机。
- **双线索**：① 监控画面左手；② P03 聊天沈苒说"我用右手写字"。

### CLUE_HALF_SHENRAN ★情感核心★
- **来源**：P11 真假消息分辨。
- **内容**：玩家选出真沈苒的消息（提到"芝麻"猫），她短暂夺回控制。
- **真相**：沈苒被寄生后保留部分意识，与母体拉锯——可"教"（短暂唤醒），不可"救"（无法脱离母体）。

### CLUE_ONLY_WAY_OUT
- **来源**：P11 真沈苒的告白。
- **内容**：唯一出路是让证据离开这座山——但无论选哪条路，她都回不来了。

### P08/P09/P11 提示（三级）
**LOGIN_P08**：L1 门禁要的是"负责人"信息 / L2 看访客登记表里谁的工位在 B 区 / L3 林叙之 LXZ + B-07 = lxzb07
**SEARCH_P09**：L1 档案里有关于"主体局限"的记录 / L2 试试搜"离山"或"根脉" / L3 输入"离山"，看实验日志
**IDENTIFY_P11**：L1 真沈苒会知道只有你们俩的私密事 / L2 想想她聊过的宠物 / L3 选提到"芝麻"那条
