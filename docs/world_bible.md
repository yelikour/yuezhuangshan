## 1. 核心概念：母体 (The Mother)

深山地下存在一种**植物、真菌与动物组织混合的生命体**，暂称"母体"。

### 1.1 起源与演化

| 阶段 | 能力 |
|------|------|
| 最初 | 寄生植物，进行光合作用 |
| 中期 | 开始吸收动物，保存濒死动物的脑组织 |
| 后期 | 通过神经状菌丝读取和模仿记忆 |
| 近代 | 随宿主增多，学会捕猎、生态管理、人类语言、宗教组织、现代科研 |

### 1.2 母体的本质局限（核心规则，永不可违反）

1. **无法自由离开岳桩山** —— 母体主体与地下生态结合，不可移动。普通孢子离山后不能长期存活。
2. **完整读取记忆需要保持脑组织活性** —— 死亡脑组织无法读取。
3. **擅长模仿与拼接，缺乏真正原创理解** —— 它能复述、重组，但不能"想出"全新概念。它的宗教教义、科研术语都是从外来者记忆里拼来的，常有缝合痕迹。
4. **催眠需要介质、时间和脆弱状态** —— 必须依靠山泉、孢子或低频振动；对衰弱、精神不稳定或长期暴露者效果更强。无法瞬间、远程、无介质控制正常人。
5. **并非全知** —— 只知道被吸收宿主曾经知道的信息。宿主不知道的事，母体也不知道。
6. **避免大规模杀戮** —— 需要维持食物、隐蔽性和村庄生态。它偏好"自愿消失"而非屠杀。
7. **火能毁坏表层网络、实验室和样本** —— 但难以彻底杀死地下母体。
8. **需要适配的人类宿主** —— 才能把"记忆核心备份"带往山外。这是它当前最迫切的目标。

## 2. 地名与传说

### 2.1 岳桩山

- 古称"**瘴山**"（文献用名）。
- 民间讹称"**脏山**"。
- 现名"**岳桩山**"，源自岳姓先民。

### 2.2 岳桩村

- 岳姓先民在山谷入口立下一根木桩，将聚落命名为**岳桩村**。
- 将山改称**岳桩山**。
- 木桩后来被称为"**岳圣桩**"。

### 2.3 三年一度的传统

- 约一千年前，村民发现每隔三年：山溪变浑、牲畜不安，随后一些濒死老人会**自行进入深山**。
- 老人消失后，次年庄稼通常丰收（实为母体回报的生态管理）。
- 村里逐渐形成传统：**每三年正月初十，将老人送至岳圣桩**。
- 这是母体与村庄之间维持千年的"契约"。

> **真相**：濒死老人被母体吸收，其记忆成为母体的一部分。丰收是母体对村庄的回馈，也是它维持自身隐蔽与食物来源的策略。

## 3. 合奘教 (虚构宗教组织)

### 3.1 起源

- 近一两百年，母体从外来者记忆中学会宗教组织形式。
- 借精神薄弱者创建"**合奘教**"。

### 3.2 教义关键词

- "**合奘**"在教义中表示"**肉身归山、记忆合一**"。
- 这是母体"吸收宿主记忆"这一生物过程的神学包装。

### 3.3 现实对应（仅供开发理解，绝不出现在游戏内）

- 合奘教 = 母体管理"食物来源（自愿献身者）"的近代界面。
- 教义中的"合一"= 神经菌丝读取记忆。

## 4. 近现代：科学家与公司

### 4.1 科学家（代号：林博士 / 对外身份"林叙之"）

- 近二十年，一名研究**神经再生**的科学家发现母体并与其合作。
- 母体为他修复身体（他原本有严重伤病）。
- 科学家提供：不同物种样本、特殊职业人群、实验设备。
- **关键反转**：科学家自认在利用母体，实际可能早已成为母体的人类代理。

### 4.2 岳桩生态文化发展有限公司

- 近几年，组织通过该公司将当地包装成**景区**。
- 举办"**地方异闻与悬疑叙事创作研讨会**"。
- **真实目的**：筛选记者、作者、医生、音乐家和研究人员——寻找能携带母体记忆核心的适配宿主。

## 5. 主角与女友

### 5.1 主角

- 身份：**推理小说作者**。
- 被选中的真正原因：组织认为他能**整合矛盾信息、模拟不同人格**，是理想的"记忆容器"。
- 玩家越擅长调查，越证明自己适合成为母体的容器——这是游戏的核心讽刺。

### 5.2 女友（代号：沈苒 / 对外笔名"沈一苒"）

- 与主角一同来到岳桩山参加会议。
- **提前察觉异常并主动调查**，之后进入山中**失踪**。
- 她被寄生后**仍可能保留部分意识**。
- 通过聊天、照片、账号活动留下**真假混杂的线索**。
- 切片结尾她"已关机"的账号发来"别来找我，我已经回来了"，但照片细节暴露发信者并非她本人。

## 6. 核心主题

1. **记忆是否等于人格** —— 母体能复制你的记忆，那"你"还是你吗？
2. **利用与饲养的倒置** —— 人类利用自然 vs 自然饲养人类。
3. **管理界面的演变** —— 信仰、科学、旅游商业，只是同一生物在不同时代使用的"管理界面"。
4. **能力的诅咒** —— 玩家越擅长调查，越证明自己适合成为母体的容器。
