## 第一阶段（P00–P07）

### P00 导航首页
- **URL**：`/yuezhuangshan/`
- **操作**：
  - 新玩家：点收藏栏橙色「▶ 开始调查」或侧栏邮箱「云雁邮」
  - 老玩家：收藏栏显示已解锁节点，点对应入口继续
  - 右上角「⚙ 设置」可调音量/静音/减少动态/字幕
- **检测点**：
  - [ ] 顶部搜索栏搜任意词（如"天气"）应在新标签页打开百度
  - [ ] 搜"岳桩"应跳转游戏（景区页）
  - [ ] 导航项（天气预报、火车票等）点击在新标签打开真实网站
  - [ ] 外部链接与游戏入口（云雁邮等）视觉一致，难分辨

### P01 邮箱（云雁邮）
- **入口**：首页点「云雁邮」（带红点 1）
- **操作**：依次点开 4 封邮件：邀请函、会议日程、入住资料、推广
- **关键邮件**：
  - **邀请函**：解锁 P02/P03
  - **入住资料**：含会议账号 `protagonist@yuezhuangshan-conf.cn` + 口令规则
- **检测点**：
  - [ ] 底部不应有"调查入口"引导文案（已删除）
  - [ ] 邮件列表有发件人头像
  - [ ] 顶部「返回导航首页」能正常回首页（不 404）

### P02 景区官网
- **入口**：首页资料库栏「岳桩山景区」或邮箱后自行前往
- **操作**：在搜索框输入 `岳圣桩`（或"桩""传说"）→ 点搜索
- **答案**：命中词 `岳圣桩 / 桩 / 传说 / 敬老 / 岳桩山`
- **解锁**：传说页（三年一度送老传统）
- **支线**：传说页底部「〔古籍残页·岳桩县志〕」可点开（可选）
- **检测点**：
  - [ ] hero 背景图（云雾山）正常显示
  - [ ] 传说页有岳圣桩照片
  - [ ] 搜索无关词（如"天气"）应提示未找到

### P03 聊天（谛听）
- **入口**：首页资料库栏「谛听」
- **操作**：阅读沈苒的消息序列（自动解锁线索）
- **关键线索**：
  - 18:48 提到猫"**芝麻**"（P11 伏笔）
  - 19:42 饮用水怪味 + 水杯照
  - 19:58 "我用**右手**写字"（P10 伏笔）
  - 20:15 对称菌斑照
  - 21:03 失联
  - 19:15 参会证尾号 **0427**（P05 伏笔）
- **解锁**：P04（读完失联自动开放）
- **检测点**：
  - [ ] 水杯照、菌斑照正常显示
  - [ ] 菌斑照出现时有水滴音效（需开声音）
  - [ ] 线索整理列表完整

### P04 资讯搜索（岳桩资讯）
- **入口**：首页资料库栏「岳桩资讯」（需先完成 P03）
- **操作**：搜索框输入 `失踪`（或"失足""岳圣桩""周某"）
- **答案**：命中词 `失踪 / 失足 / 岳圣桩 / 周某`（同义词：走失、下落不明也命中）
- **关键**：点开★标记的旧报道（2019-02-14），阅读正文
- **矛盾点**：标题"自行失足" vs 正文"自愿返回"；家属栏空白
- **解锁**：P05
- **检测点**：
  - [ ] 旧报道有报纸质感背景
  - [ ] 解谜后显示"你发现了什么"总结 + 通往后台链接

### P05 后台登录（研讨会工作台）
- **入口**：P04 解谜后的链接，或首页资料库栏「研讨会工作台」
- **操作**：输入账号 + 口令
- **账号**：`protagonist@yuezhuangshan-conf.cn`（大小写/空格不敏感）
- **口令**：`0427ywyxxsc`（参会证尾号 0427 + 研讨会拼音首字母 ywyxxsc）
  - 等价写法：`0427-YWYXXSC`、`0427 ywyxxsc` 等都能通过
- **来源**：账号→邀请函；尾号→聊天；规则→入住资料
- **解锁**：P06（登录成功后切到记录视图）
- **检测点**：
  - [ ] 输错有错误计数 + 自动升级提示
  - [ ] 点"我卡住了"可手动请求提示（三级）

### P06 房卡记录
- **入口**：P05 登录后自动显示
- **关键记录**：
  - 23:47 岳圣桩维护通道（外层）⚠ 失联后 2h44m
  - 02:11 岳圣桩维护通道（内层）⚠ 进入更深
- **矛盾**：沈苒 21:03 失联，房卡却在失联后仍被使用
- **解锁**：P07
- **检测点**：
  - [ ] 监控截图（lab_blur）正常显示
  - [ ] "手机震了一下"有震动音效（需开声音，1.2s 延迟）

### P07 第一阶段结尾
- **入口**：P06 的「查看消息」链接
- **演出**：沈苒假消息逐字显示 → 照片 + 三条矛盾细节 → 阶段总结
- **照片矛盾**：祭祀袍 / 工牌挂钩 / 时间戳 02:11
- **解锁**：P08（第二阶段开始）
- **检测点**：
  - [ ] 氛围底噪循环播放（需开声音）
  - [ ] reduce-motion 下逐字动画改为直接显示
  - [ ] 「返回导航首页」不 404

## 第二阶段（P08–P12）

### P08 lab 门禁
- **入口**：首页资料库栏「实验室内网」（需完成 P07）
- **操作**：看访客登记表 + 工位图，推断身份码
- **答案**：`lxzb07`（林叙之 LXZ + 工位 B-07）
  - 等价写法：`LXZ-B07`、`lxz b07` 等都能通过
- **来源**：访客登记表"林叙之 工位 B-07" + 工位图确认
- **解锁**：P09（切到档案视图）
- **检测点**：
  - [ ] 输错有错误计数 + 提示
  - [ ] 通过后出现「档案检索 / 监控回放」tab

### P09 档案检索
- **入口**：P08 通过后的档案视图
- **操作**：搜索关键词，点开★关键档案
- **必看档案**（按顺序）：
  1. 搜 `离山`（或"根脉""主体"）→ 打开「主体迁移局限性验证」
     - 揭示：母体无法离山，需 S 级容器
  2. 搜 `容器`（或"适配""诱饵"）→ 打开「宿主适配性评估报告」
     - 揭示：**主角 = S 级理想容器**；**沈苒 = B 级诱饵**
- **解锁**：P10（看完评估报告后出现「查看监控回放」）
- **检测点**：
  - [ ] 档案有密级标注（机密/绝密）
  - [ ] 评估报告正文含主角评级 S、沈苒用途"诱饵"

### P10 监控录像
- **入口**：P09 后点「查看监控回放」tab
- **内容**：02:11 监控画面（黑白、信号干扰、REC 闪烁）
- **关键破绽**：通行者用**左手**按闸机（沈苒是右撇子）
- **解锁**：P11
- **检测点**：
  - [ ] 监控画面有 REC 红点闪烁（reduce-motion 下静止）
  - [ ] "那不是她"揭示 + 「查看消息」链接

### P11 半沈苒真假消息
- **入口**：P10 的「查看消息」→ 未知号码页
- **操作**：5 条消息真假混杂，选出真正的沈苒说的那条
- **答案**：选第 **2** 条（"芝麻今天又把杯子推下桌了……"）
  - 判断依据：真沈苒知道私密小事（猫"芝麻"）；母体只会说"第一次见面""重新开始"等大词
- **解锁**：P12（选对后真沈苒告白 + 「做出选择」链接）
- **检测点**：
  - [ ] 选错有提示"记忆太大，它学的就是这种"
  - [ ] 选对后高亮选中项 + 显示真沈苒告白
  - [ ] 提示系统三级可用

### P12 三结局
- **入口**：P11 的「做出选择」
- **操作**：三选一（无对错，可试不同选择）
  - **壹·提交档案**：证据外泄，公司查封，但母体仍在；沈苒失踪
  - **贰·销毁实验室**：火烧表层，带走沈苒最后一缕菌丝
  - **叁·成为容器**：获得母体记忆，"笑容偶尔不太像你"
- **检测点**：
  - [ ] 每个结局文字逐段显示（reduce-motion 下直接显示）
  - [ ] "成为容器"结局背景渐黑
  - [ ] 氛围底噪贯穿（需开声音）
  - [ ] 「返回导航首页」不 404

### 无障碍检测
- [ ] 默认静音（不自动播放声音）
- [ ] 设置里开「减少动态效果」后：动画停止、闪烁静止、音效静音

- [ ] 所有交互可用键盘 Tab + Enter 操作

### 常见问题排查
| 现象 | 原因 | 解决 |
|------|------|------|
| 返回首页 404 | 本地 dev 用了错 URL | 用 `localhost:5173/yuezhuangshan/`（带子路径） |
